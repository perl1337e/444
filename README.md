# Mod Manager

Менеджер модов на Tauri 2 + Svelte (тот же стек, что у Gale).
Источники: Мастерская Steam, Thunderstore, Nexus Mods. Темы: белая, тёмная, тёмно-синяя.

## Запуск

Нужны: Node.js 20+, Rust (rustup), на Windows ещё WebView2 и MSVC Build Tools.

    npm install
    npm run tauri dev       # разработка
    npm run tauri build     # установщик

## Как работает

- **Вставить ссылку**: Steam Workshop, страница мода на Thunderstore, `nxm://`-ссылка Nexus.
- **Браузер Мастерской**: кнопка «Добавить в менеджер» появляется рядом с «Подписаться».
  Скачивание идёт через SteamCMD (путь указать в настройках).
- **Thunderstore**: поиск по игре, установка вместе с зависимостями. Протокол `ror2mm://`
  зарегистрирован, кнопка «Install with Mod Manager» на сайте открывает это приложение.
- **Nexus**: протокол `nxm://` зарегистрирован, кнопка «Download with manager» на сайте
  отдаёт ссылку приложению. Нужен личный API-ключ (настройки аккаунта Nexus → API).

## Ограничения первой версии

- Код не проверялся компиляцией, возможны мелкие правки при первой сборке.
- Моды раскладываются по папкам внутри «папки с модами» (по умолчанию в данных пользователя).
  Копирования в папку игры и профилей, как у Gale, пока нет.
- Nexus: архивы .7z и .rar сохраняются как есть, распаковывается только .zip.
- Кнопка в браузере Мастерской может сломаться, если Steam изменит вёрстку страницы.
- Для части игр SteamCMD требует вход с аккаунтом, который владеет игрой.

## Структура

    src/routes/+page.svelte   интерфейс (вкладки, журнал, настройки)
    src/lib/settings.ts       настройки и тема (хранятся в localStorage)
    src/app.css               цвета трёх тем
    src-tauri/src/lib.rs      команды: разбор ссылок, Thunderstore, Steam, Nexus

## Готовый установщик без установки Node и Rust

1. Создай репозиторий на GitHub и загрузи туда этот проект (ветка `main`).
2. Открой вкладку **Actions**, выбери **Build installer**, нажми **Run workflow**.
3. Через 10–15 минут в результатах запуска появится артефакт `mod-manager-windows`:
   внутри `.msi` и `.exe` установщики. Скачай и запускай как обычную программу.
